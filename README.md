# 超星学习通 · 未完成作业 / 考试提取

一个 Windows 桌面小工具：登录学习通后，把**还没做的作业、还没考的试**一次性列出来，按「未完成 / 超时未交 / 已完成」分块显示，可以导出 CSV 或日历。

**只读**。不提交作业、不答题、不改动任何数据。

---

## 为什么会有这个工具

学习通的课程、作业、考试分散在不同页面，一门一门点进去看截止时间很费事，很容易漏。这个工具做的就是：一次扫描全部课程 → 合并作业和考试 → 按紧急程度排好 → 告诉你哪些快到期了。

同时它把「登录态」当成敏感数据对待：加密存储、只读使用、不写日志、不落原始页面。

---

## 功能

| 功能 | 说明 |
|---|---|
| 三种登录方式 | 账号密码直登 / 粘贴或导入 Cookie / 复用本机已保存的登录态 |
| 一次性扫全量 | 所有课程的作业 + 考试，自动翻页，结果合并去重 |
| 三块分组 | 未完成 / 超时未交 / 已完成，按紧急程度排序（紧急的在上） |
| 任意筛选 | 三个开关随意组合，至少保留一块，切换时整表重画不留空行 |
| 双击直达 | 双击任意一行，在浏览器打开对应的作业 / 考试页面（仅查看） |
| 导出 | CSV（含分类列）、ICS 日历（可导入 Outlook / 日历 / 手机） |
| 多分辨率适配 | 按 DPI 自动缩放，页面可滚动，窗口高度随内容收缩 |
| 新老界面兼容 | 同时支持学习通的新版（Vue / mooc-ans）和老版页面 |

## 快速开始

1. 从 [Releases](../../releases) 下载 `超星作业提取.zip` 并解压（或自己按下面的说明打包）；
2. **放到你有写权限的目录**（桌面、D 盘某个文件夹），不要放 `C:\Program Files`；
3. 双击 `超星作业提取.exe` 运行，选择一种登录方式，点「登录并提取」；
4. 结果按三块列出来，点开关可以只看其中一块或两块。

首次运行会提示创建 **CookieKey**（见下文），创建一次就能长期复用登录态。

### 三种登录方式

- **账号密码** —— 直接登录学习通。密码只在本次登录的内存里用，不保存、不上传（界面上也这么写着）。
- **Cookie 导入** —— 从浏览器导出 Cookie 后粘贴，或点「选择 Cookie 文件…」导入 `.json` / `.txt`。
- **已保存登录态** —— 之前登录过、且 `cookie/session.dat` 还在、且检测到本机的 `CookieKey`，就能直接「提取」，不用重新登录。

---

## 分块规则

每条任务在提取时就判定归属：

1. **已完成** —— 作业已交 / 考试已交卷。**优先判定**，哪怕截止时间已过也算完成；
2. **超时未交** —— 没做，且截止时间已经过去。没有具体时间但考试状态为「已结束」的也归这里；
3. **未完成** —— 还没到期。拿不到时间的一律当作待办（宁可提醒你别漏，也不误判成超时）。

表格排列顺序就是 **未完成 → 超时未交 → 已完成**。三块的视觉区分：

| 块 | 行底色 | 状态列 |
|---|---|---|
| 未完成 | 白色 / 淡蓝斑马纹 | 原状态（未交、进行中…） |
| 超时未交 | 淡红 | 超时未交 |
| 已完成 | 淡灰、灰字 | 已完成 / 已批阅 / 已交卷 |

## 隐私与安全设计

这一节是这个项目最花心思的地方，也是它和「直接抓包脚本」的区别。

### 1. Cookie 只加密保存，且只读使用

- 登录态写在 `cookie/session.dat`：**AES-256-CTR** 加密 + **HMAC-SHA256** 完整性校验，密钥用 **scrypt**（N=16384, r=8, p=1）从子密钥派生；
- 程序其余部分拿到的是只读视图（`ReadOnlyCookies`），**禁止导出、禁止写回、禁止遍历外传**；
- 软件不写操作日志，不记录课程名、作业名、截止时间，也不保存任何原始网页快照。

### 2. CookieKey —— 每台电脑只能创建一次，且绑定本机

CookieKey 是「Cookie 的钥匙」，一个 99 字节的小文件：

- **独立随机 32 字节**，不从主密钥派生，创建时**不需要插 U 盘、不需要任何解锁权限**；
- **每台电脑只能创建一次**：创建后写一个 `.cookiekey.lock` 标记，之后即使把 CookieKey 删了、移走了，也不允许再生成；
- **与创建它的这台电脑绑定**（格式 v3）：包裹密钥里掺入本机硬件指纹，**复制到别的电脑就是废文件**，解不出密钥；
- 在同一台电脑上，它可以随意复制、换目录 —— 把所在文件夹加进「检测目录…」就能自动识别。

为什么绑定本机？因为「文件本身即钥匙」意味着谁拿到文件谁就能解密。绑定之后，文件泄露到别的机器上等于无用数据，而你自己换电脑只需要重新创建一把。

> 需要说明的是：「只能创建一次」是**防误操作**的软约束 —— 删掉 `.cookiekey.lock` 技术上可以重建。但重建会换掉整个 32 字节密钥，之前用旧钥匙加密的登录态就永远解不开了，等于自毁，所以没有实际收益。

### 3. 管理 U 盘（可选）

如果你还想多一层保护，可以在隐私窗口里注册一个 U 盘：

- 主密钥不落盘明文，由 **scrypt(本机指纹 + U 盘硬件序列号)** 包裹；
- 只有插着这个 U 盘才能查看和管理「硬件成员名单」；
- 可以生成**备份钥匙文件**（可选口令），复制到任何地方都能用来解锁 —— 用于 U 盘丢失或损坏时的补救。

不注册 U 盘也完全能用，只是少了这层保护。

### 4. 加密实现没有第三方依赖

AES-128/192/256（CBC/CTR）、HMAC-SHA256、scrypt、PBKDF2 全部是**纯标准库实现**，没有引入 `pycryptodome` 之类的加密库。运行期第三方依赖只有 `requests` 和 `beautifulsoup4`（用于抓取和解析页面）。

## 运行时生成的文件

```
超星作业提取.exe
CookieKey              ← 本机钥匙，建议备份（换电脑/重装需要）
.cookiekey.lock        ← 「已创建过」的标记
cookie/session.dat     ← 加密的登录态
device/keys.dat        ← 主密钥封包（用了 U 盘保护才有）
device/members.dat     ← 硬件成员名单
.cookiekey.dirs        ← 额外检测目录（加过才有）
```

**想彻底清干净**：删掉 `CookieKey`、`.cookiekey.lock`、`cookie/`、`device/`、`.cookiekey.dirs` 即可。也可以直接点界面上的「退出登录并清除」。

**备份**：只需要备份 `CookieKey`（以及 `device/` 目录，如果你用了 U 盘保护）。

## 从源码运行

```bash
pip install requests beautifulsoup4
python app.py
```

系统要求：Windows 10 / 11，Python 3.9 及以上（源码运行时需要 Python 自带 tkinter）。

命令行也可以直接用（不带界面，输出到终端或 CSV）：

```bash
python chaoxing_extractor.py --cookies-file cookies.txt
python chaoxing_extractor.py --cookies "uf=xxx; _uid=123" --all --output out.csv
python app.py --selftest          # 内置自检，结果写在 selftest_log.txt，末尾应为 RESULT=OK
```

## 自己打包 exe

双击 `build_exe.bat` 即可，它会自动完成 4 步：

1. 检查 Python 和 tkinter（**必须用带 tkinter 的解释器**，官方安装包默认就带）；
2. 创建独立的 `.build-venv` 并安装 `requests` / `beautifulsoup4` / `pyinstaller`（优先国内镜像）；
3. PyInstaller 打包成单文件 `超星作业提取.exe`；
4. 调用 `make_zip.py` 生成发布包。

`make_zip.py` 是**白名单**打包：只放 exe、源码、脚本、图标，并且带隐私闸门 —— 一旦发现路径或文件名命中 `CookieKey` / `cookie/` / `device/` / `.dat` / `.log` 之类，会**直接中止、不生成 zip**，同时把被排除的文件打印出来。这样就不会不小心把自己的登录态发出去。

## 常见问题

**Q：换电脑 / 重装系统后，CookieKey 用不了了？**

这是设计如此。CookieKey 绑定了创建时的本机指纹（含计算机名、用户名、MachineGuid、系统盘卷序列号），换机或重装后解不开，界面会显示「文件属于另一台电脑，本机无法使用」。

补救：用管理 U 盘解锁，或在隐私窗口里把那个文件改名备份后重新创建一把。**但旧的 `cookie/session.dat` 解不开了**，需要重新登录一次。

**Q：提示「本机已经创建过 CookieKey，不能重复生成」？**

把之前备份的 `CookieKey` 放回程序目录即可；如果放在别处，点「检测目录…」把那个文件夹加进自动检测列表，程序会自动找到它。

**Q：exe 被杀毒软件报毒？**

PyInstaller 单文件打包的常见误报（会自解压到临时目录、启动子进程）。加白名单即可，或者从源码运行。

**Q：提取结果为空？**

先在浏览器里确认学习通能正常打开课程列表，再点「重新提取」。如果是刚登录完，等几秒让会话生效。老版和新版页面都兼容，但仍可能遇到学校自定义模板，这种情况下只能改解析规则。

**Q：能自动交作业吗？**

不能，这个工具**只读**。它连「打开作业页面」都是交给系统浏览器，自己不发任何写请求。
