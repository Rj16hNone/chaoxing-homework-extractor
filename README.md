# 超星学习通 · 未完成作业 / 考试提取

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

登录学习通后，把**还没做的作业、还没考的试**一次性列出来，按「未完成 / 超时未交 / 已完成」分块显示，紧急的排在前面。

**只读**。不提交作业、不答题、不改动学习通上的任何数据。

---

## 两个版本

| 平台 | 目录 | 下载 | 技术栈 |
|---|---|---|---|
| **Windows 桌面版** | [`windows/`](windows/) | `超星作业提取-安装程序.exe`（向导安装）<br>`超星作业提取.zip`（免安装） | Python 3 + tkinter |
| **安卓版** | [`android/`](android/) | `超星作业提取.apk`（约 125 KB） | 原生 Java（Android 6.0+） |

两个版本功能一致：一次扫描全部课程 → 合并作业与考试 → 三块分组 → 点一行用浏览器打开对应页面。

- 桌面版另有：导出 CSV、导出 ICS 日历、双击行打开、DPI 自适应；
- 安卓版另有：导出 CSV 到系统「下载」目录、`Keystore` 双层加密。

---

## 下载与安装

**Windows**：从 [Releases](../../releases) 下载 `超星作业提取-安装程序.exe`，双击按向导安装（默认装到 `%LOCALAPPDATA%\Programs\超星作业提取`，不需要管理员权限）。不想安装就用同页的 `超星作业提取.zip`，解压到有写权限的目录直接运行。

**安卓**：下载 `超星作业提取.apk` 直接安装（首次需允许「安装未知来源应用」）。只申请**联网**这一个权限。

两个版本第一次打开都会先显示许可与免责声明，同意后进入主界面（只弹一次）。

---

## 分块规则

每条任务在提取时就判定归属，表格顺序即 **未完成 → 超时未交 → 已完成**：

1. **已完成** —— 作业已交 / 考试已交卷。**优先判定**，哪怕截止时间已过也算完成；
2. **超时未交** —— 没做，且截止时间已经过去（没有时间但状态为「已结束」的也归这里）；
3. **未完成** —— 还没到期。拿不到时间的一律当作待办。

三块可以任意筛选，但至少保留一块。

## 隐私与安全

两个平台都遵循同一原则：**登录态只在本机加密保存，不上传、不同步，也不写日志。**

| | Windows | 安卓 |
|---|---|---|
| 加密 | AES-256-CTR + HMAC-SHA256，密钥由本机指纹派生 | Android Keystore 里不可导出的 KEK 包裹随机 DEK，DEK 再加密登录态 |
| 换机 / 重装 | 解不开，需重新登录一次 | 解不开，静默回到登录页 |
| 混淆 | PyInstaller 打包 | R8 全量重命名 + 包名压平 + 字符串编码 |
| 网络之外的数据 | 不写日志、不存原始网页 | 不写日志、不存原始网页 |

细节见 [`windows/README.md`](windows/README.md) 与 [`android/README.md`](android/README.md)。
